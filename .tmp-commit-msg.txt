## 安卓 App
只加一层壳，不给 Web 那一半加功能：Capacitor 7 把静态产物（out/）装进 WebView。
appId=com.orang1ver.yuanqiledger、桌面名「元气账本」、versionName 直接读 package.json。

三个静默失败各有一条防线：
1. 打包时构建**不能带 BASE_PATH**（子路径是给 GitHub Pages 的，WebView 从 https://localhost 起）
   —— 带上就是纯白屏，而包里看不出任何异常。build-apk.ps1 会断言产物里没有子路径前缀。
2. 没有 keystore.properties 时 assembleRelease 照样"成功"，只是产出**装不上的未签名包**
   —— 所以先断言密钥在，再用 apksigner 验一遍。密钥在 D:\Android\keystore，不入库。
3. public/sw.js 的 __VERSION__ 占位符要在打包前注入（与 deploy.mjs 同一套替换），
   否则缓存名恒定，装上新版之后旧缓存还在。

本机 dl.google.com 直连不通，SDK 从腾讯镜像手工铺目录、依赖走阿里云镜像。
镜像上没有 build-tools 35，于是 AGP 8.6.1 + Gradle 8.11.1 + compileSdk 35 + build-tools 34.0.0
四个被一起钉死。Capacitor 的两个子模块各自硬编码 AGP 8.7.2 且从 google() 拉，
node_modules 不能改，所以在 android/build.gradle 里为所有子工程前置镜像 + 压 AGP。

## 修掉 maskable 图标的环偏心
make-icons.py 的 maskable_logo 把 w*0.62 当 size 传给 mark_color，而 mark_color 以 size/2 为中心
—— 环连同中心被挪到左上角。实测（读 git 里那份 PNG 算外接框）偏 137.2px，即画布的 26.8%。
改成给 mark_color 加 scale（只缩半径、不动中心），启动图与自适应图标走同一条路。

补了一条自证过的断言：出图前算环的外接框中心，偏移超过 1.5px 就报错。
判据用外接框而不是像素重心 —— 环是 300° 弧，缺口本来就会把重心拉偏（实测 18.6px）。
自证：把"用小画布"那个错法塞回去，断言报出 137.2px，与旧图标实测值完全一致。
